# コード帳

ギターの弾き語り練習用に作った、コード譜のコレクションアプリ。iPhone で見る前提の PWA です。

自分の手元にあるコード譜を貯めて、見やすく表示するための道具です。曲データは端末の中に保存され、Dropbox 同期を有効にした場合だけ、あなたの Dropbox の専用フォルダに送られます。

## できること

| | |
|---|---|
| **画像から読み取る** | スクリーンショットを貼り付け（Ctrl+V）またはファイル選択。**画像は端末内だけで処理し、どこにも送りません**。複数枚を続けて読むと、重なっている行を自動で落として下に足していきます |
| **テキストから読み取る** | コード譜を貼り付け。「歌詞の上にコードが並ぶ」形式を解析します。ページごと全部コピーして貼っても、譜面の部分だけを取り出します |
| **直す箇所の案内** | 読み取れなかった語と、曲のキーから外れた疑わしいコードをボタンで並べます。タップすると本文のその場所が選ばれるので、そのまま上書きできます |
| **曲名の照合** | 誤読した曲名・アーティスト名を、ネットの楽曲検索で正式名称に直せます（ボタンを押した時だけ通信し、送るのは曲名とアーティスト名だけ） |
| **表示** | 歌詞の上にコードを配置。全角・半角の桁を計算して位置を合わせます |
| **押さえ方** | コード名をタップすると押さえ方が出ます。分数コード（`D/F#`、`GonA` など）もベース音を再現します |
| **転調** | 半音単位で上下。♯/♭はキーの慣用表記に自動で合わせます（C から +3 なら `D#` ではなく `Eb`） |
| **カポ** | 押さえるコードだけが下がり、鳴るキーは変わりません。開放弦で弾けるカポ位置を提案することもあります |
| **その他** | 文字サイズ7段階／一定速度のオートスクロール／画面スリープ防止／ダーク・ライト切替／バックアップの書き出しと読み込み |

## 使い方

**https://ks-kit.github.io/chord-book/**

開いて、Safari の共有ボタン →「ホーム画面に追加」でアプリのように使えます。オフラインでも開けます。

**PC では**、Chrome か Edge で開き、右上の ⋯ メニュー →「PC にアプリとして追加」を押すと、スタートメニューやタスクバーから独立した窓で開けます（アドレス欄の右端に出るインストールのアイコンからも追加できます）。
フォルダの `コード帳を開く.bat` をダブルクリックしても、同じ公開版をアプリの窓で開きます。曲は Dropbox 同期で iPhone と共有されます（その窓で1回だけ接続が必要）。

1. ＋ を押す
2. コード譜のスクリーンショットを貼り付ける（または本文を貼り付ける）
3. 読み取れなかった箇所を直す
4. 曲名を入れて保存

コード譜サイトのスクリーンショットを撮るときは、**押さえ方図の表示をOFFにし、譜面の部分だけを切り取る**と精度が上がります。

## メトロノーム

曲の画面の下のツールバーにあります。テンポと拍数は曲ごとに覚えます。

- **♩** で鳴らす／止める。小節の頭は高い音で鳴ります
- **数字を直接入力**するか、**−／＋** で1ずつ調整
- **タップ** を押すと、曲に合わせて「たん、たん、たん」と叩いた間隔から BPM を自動で出します。叩き損ねた1回は自動で除外します。PC ではスペースキーでも叩けます
- **4拍** を押すと 2・3・4・6拍 を切り替えます

## 端末間の同期（Dropbox）

PC と iPhone で曲を共有できます。曲データはあなたの Dropbox の**このアプリ専用フォルダ**（`アプリ/<アプリ名>/songs.json`）にだけ置かれ、Dropbox の他のファイルには触れません。

### 最初に1回だけ: Dropbox 側の準備（5分）

1. https://www.dropbox.com/developers/apps を開き、**Create app**
2. **Scoped access** を選ぶ
3. アクセスの種類は **App folder** を選ぶ（Full Dropbox ではなく）
4. アプリ名を付ける（全世界で重複しない名前。例: `chord-book-自分の名前`）→ **Create app**
5. **Permissions** タブで次の2つにチェックを入れて **Submit**
   - `files.content.write`
   - `files.content.read`
6. **Settings** タブの **OAuth 2 → Redirect URIs** に次を追加
   - `https://ks-kit.github.io/chord-book/`
   - `http://localhost:8766/`（手元で動かす場合）
7. 同じ **Settings** タブに「Allow public clients (Implicit Grant & PKCE)」があれば **Allow** になっていることを確認
8. **Settings** タブの **App key** を控える

> 手順5の権限は、**接続する前に**設定してください。接続したあとで権限を変えた場合は、アプリで一度「接続を切る」→ 接続し直す必要があります。

App key は公開してよい値です（秘密鍵ではありません）。このアプリは秘密鍵を使わない PKCE 方式で接続します。

### 各端末で接続する

1. メニュー（⋯）→ **Dropbox と同期**
2. **Dropbox に接続する** を押す（公開版には App key を組み込み済みなので、貼り付けは不要）
3. Dropbox の画面でログインして許可
4. iPhone のホーム画面から開いている場合は、**コードを貼り付ける方法**で接続します（ホーム画面のアプリは Safari と保存領域が別なので、自動では戻ってこられないため）

あとは曲を保存・削除すると自動で同期します。アプリを開き直したときも同期します。

同じ曲を2台で同時に直した場合は、**あとから保存したほう**が残ります。

## 手元で動かす

```
python .claude/devserver.py 8766
```

ブラウザで `http://localhost:8766/` を開きます。同じ Wi-Fi の iPhone から見るときは `--lan` を付けます。

## 作り

依存パッケージなし、ビルド不要の素の HTML / CSS / JavaScript です。

| ファイル | 役割 |
|---|---|
| `index.html` | 3画面（ライブラリ／編集／表示）の骨組み |
| `app.js` | 保存、画面遷移、転調・カポ、オートスクロール |
| `chords.js` | コード名の解析・移調・押さえ方図（SVG）の生成 |
| `parser.js` | 貼り付けたテキストの解析 |
| `ocr.js` | スクリーンショットの読み取り |
| `metronome.js` | メトロノーム（Web Audio の先読み予約）とタップテンポ |
| `sync.js` | Dropbox との同期（PKCE 認証・曲ごとのマージ） |
| `vendor/` | [tesseract.js](https://github.com/naptha/tesseract.js) と言語データ |

設計上の判断と実測値は [CLAUDE.md](CLAUDE.md) に書いてあります。

## 曲データについて

- 曲データは端末の `localStorage` に保存されます。このアプリ用のサーバはありません
- 端末間で共有するには Dropbox と同期します（上記）。置き場所はあなたの Dropbox のアプリ専用フォルダで、非公開です
- 同期しない場合は、メニューからバックアップを書き出して読み込むこともできます
- 同梱しているサンプル曲「ふるさと」は、作詞・作曲者の権利が消滅しているものです
